Open [Releases](https://github.com/dioufseck-rgb/techgraph/releases/tag/backup-2026-09-29) and download **Techgraph_Complete.zip** from the complete research backup dated 2026-09-29. Extract the archive and read `Techgraph_Complete/START_HERE.md`. Keep each checkpoint in a separate directory to preserve the different model versions.


## Current research state


The principal campaigns contain 910 accepted histories and 63,232 periods across 56 world ancestries. Raw retries and earlier campaigns are retained in the backup but must not be counted as additional independent observations.


The paper includes van Wyk, mismatch theory, Campbell variation and selective retention, integration capacity, complementarity traps, and entrenchment. The real-world cases document is an initial sourced review; the detailed single-finding case study remains unfinished.
