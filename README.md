# Techgraph

Techgraph is a network model of technological change. It represents needs and resources as substances, and technologies as performing three functions on them: processing, transport and storage. Institutions shape which responses are possible and who pays for them.

This repository contains version 4 of the model.

- `START_HERE_V4.md` and `README_V4.md` describe the model and how to run it.
- `techgraph/` contains the model package.
- `tests/` contains the test suite.
- `genx_bench/` contains the verification benchmarks against GenX.
- `TECHGRAPH_SPACE_AND_POLICY_DESIGN.md` describes the spatial layer and the generic policy primitives.
- `INSTITUTIONS.md`, `REPRESENTATIVE_DAYS.md` and `DEMANDS.md` describe the v4 extensions.
- `cases/` contains applications to real geographies: Virginia data centers and power, and the Potomac water supply.
- `HANDOFF.md` records the current state of the work and the next steps.
